# 近藤接骨院 レスポンシブサイト（サンプル）

## すぐ見る
ZIPを解凍して `index.html` をダブルクリックしてください。

- スマホ：縦1列・下部にLINE/電話ボタンを固定
- PC：横並びレイアウト・上部ナビゲーション表示
- 画面幅に応じて自動で切り替わります

## GitHub Pagesへの公開
1. GitHubで新しいリポジトリを作成
2. `index.html` と `assets` フォルダをそのままアップロード
3. Settings → Pages
4. Sourceを `Deploy from a branch`
5. Branchを `main`、フォルダを `/root` にして保存
6. 数分後に公開URLが表示されます

## 公開前に必ず差し替えるもの
- 公式LINEのURL
- 電話番号の確認
- 正式な院長名・資格・紹介文
- 料金（現在は 00円）
- 受付時間・休診日
- 本物の院長・院内・施術写真

## 写真差し替え
`assets` の同名ファイルを置き換えるだけでも変更できます。
- hero.webp
- doctor.webp
- room.webp
- oxygen.webp
- clinic.webp
- kids.webp
